# nix-command-guard

Nix-packaged command guardrails for AI coding agents, with emphasis on destructive shell operations and homelab-sensitive actions.

## Initial Scope

- classify risky commands before execution
- enforce deny/confirm/warn decisions
- support policy tuned for git, filesystems, infra, and remote hosts
- expose agent-friendly output and audit logs
